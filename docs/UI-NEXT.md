# 第二阶段：界面调整准备

第一版可用程序已单独交付在 `dist/Telysta-Windows-x64.zip`。本文件记录后续界面调整范围；这些设计尚未应用到首版程序。

## 目标与依据

先解决当前界面拥挤、装饰文字过多、主操作不突出的问题。
依据用户提供的 AK/UI System、编辑部排版、日本平面图形方向，以及最新的 `pastel-campus-desktop-ui` 桌面规范。
以真实功能和易用性为主，图形与文化元素保持少量；不添加虚构状态、无意义编号或人物大图。

参考：[AK/UI 设计语言](https://ak-ui.yyj.moe/guide/design-language)、[语义 Token](https://ak-ui.yyj.moe/guide/tokens)。

## 首轮调整

1. 移除只有一个主要入口的侧栏，缩减品牌区和装饰标语。
2. 主区突出素材导入与书籍队列；输出格式、保存位置放在较轻的次要区域。
3. 作者、转码质量、阅读方向等设置按需展开。
4. 封面改为队列缩略图或按需预览，释放常驻大预览区占用的空间。
5. 建立集中管理的颜色、字体、间距、几何和交互状态 Token。
6. 正文和控件优先可读性，衬线字体只承担少量标题角色，使用统一的细线图标。

首版保持现有 Rosé Pine 配色。后续对照最新附件调整色系与排版，不在首版交付期间混入未验证的换肤。

## 保留与验证

- 保留 Rust、eframe、原生窗口与文件选择框，以及已经通过测试的转换逻辑。
- 保留批量转换、拖放、进度、取消、重试和同名文件保护。
- 分别检查空状态、单本、多本、处理中、失败和完成状态。
- 在常见桌面窗口尺寸与高 DPI 下检查布局、文字截断和键盘焦点。
- 最后重新构建 Windows `.exe` 与便携包，提供新界面截图，验证基本制作流程。
