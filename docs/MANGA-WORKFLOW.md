# 本地漫画图片包与编号规则

本项目主要面向禁漫天堂（JM）导出的本地漫画图片压缩包，也可处理自行收集并编号的漫画图片。
输入是已经获得的本地文件；软件不负责站点登录、下载或对图片进行还原。

## 推荐输入

```text
一册漫画.zip
  0001.jpg
  0002.jpg
  0003.webp
  ...
```

将 ZIP、CBZ、7Z、RAR 等文件拖入窗口，或者使用「选择文件」。JPEG / PNG / WebP 都可以混合使用。
选择多个压缩包会各自成书；同时选择多张单独的图片会合并成一本。

## 首页与封面

程序按文件名自然排序。`0001`、`0002`、`0010` 的顺序与 `1`、`2`、`10` 一致。
**排序后的第一张图片同时用作 EPUB 的封面和第一张阅读页**，因此建议将封面命名为 `0001.jpg`、`0001.png` 或 `00001.webp`。
不会额外插入一张文字封面，也不会重复添加封面页。PDF / CBZ 同样从这张图片开始。

如果有 `0000` 或其他排在前面的图片，它会成为实际首页；制作前可以整理文件名。

## 多章节目录

```text
漫画.zip
  01-第一话/0001.jpg
  01-第一话/0002.jpg
  02-第二话/0001.jpg
  02-第二话/0002.jpg
```

按完整相对路径自然排序，先章节、再页码。建议章节目录也使用数字编号。
一个图片文件夹会递归合并为一本书；其中发现的压缩包则各自成书。
压缩包中的文本说明等非图片文件会忽略，压缩包内再套压缩包不会自动递归打开。

## 选择格式

- EPUB：默认推荐。一图一页、固定版式，第一张为封面。正常方向 JPEG / PNG 尽量保留原图，WebP 等会转为兼容的 JPEG。
- PDF：方便通用文档软件打开或打印，图片按原比例嵌入。
- CBZ：保留原始图片字节，适合漫画阅读器。

若原压缩包全是 WebP，转 JPEG 后文件可能变大；可以调低转码质量，或选择保留原图的 CBZ。
只有图片文件会进入成品，图片本身需要是可正常解码的文件；加密压缩包暂不支持。

汉王 N10 直接阅读 EPUB、Kindle 经 Calibre 转换后导入时的留白问题，分别见 [实体阅读器兼容性](READER-COMPATIBILITY.md)。
设备不完整支持 EPUB 固定版式时，可直接制作 PDF 作对照。

## 多本漫画并发制作

GUI 的「更多选项 → 同时制作」可设置 1–8 本，默认 2 本。

```sh
telysta-cli first.zip second.zip third.zip --jobs 3 --format epub --output ./电子书
```

并发以书籍为单位。每本书内保持编号顺序、逐页写入，避免把整套漫画解码后同时放入内存。
RAR 的解压阶段使用互斥保护；不同书籍的后续图片处理和写入仍可并行。
内存或磁盘较紧张时可设置 `--jobs 1`。

失败的书籍会保留错误原因，其余书籍继续制作。停止后会清理未完成文件，已完成的书籍保留。
同名输出使用原子保存与自动编号，不会覆盖之前的电子书。
