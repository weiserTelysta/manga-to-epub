# Telysta 界面系统 · 约束 v3

依据用户最后提供的 **Blue Archive-inspired Desktop UI 3.0** 执行，早期的衬线标题与单一蓝白卡片草案已由此版替代。

## 构图

第一视觉焦点是漫画导入工作面；右侧输出设置是较低强调的辅助区。未导入时以清晰的文件图形和操作说明引导；添加文件后导入区缩为工具条，让真实队列成为主工作区。

背景使用白蓝渐变、低透明度青色光晕和局部点阵 / 圆弧。工作面为白色，设置区为近白蓝色，选中行为浅蓝，浮层有独立边界。图形仅在背景边缘、导入区和选中标记出现，不覆盖列表正文或输入框。

不设只有一个入口的侧栏，不把每行都包成卡片。没有游戏人物、游戏 Logo、虚构编号或装饰性假状态。

## 设计 Token

Token 位于 `src/ui/theme.rs`，统一颜色、字号、间距、圆角、控件与列宽。组件消费语义角色，不按页面另造配色。

| 角色 | 校园浅色 | 校园深色 |
| --- | --- | --- |
| 背景 | `#EFF7FD` → `#E7F3FC` | `#111D2A` → `#162638` |
| 主表面 | `#FFFFFF` | `#1B2B3C` |
| 辅助表面 | `#F7FBFF` | `#21364A` |
| 选中表面 | `#EDF6FD` | `#263F55` |
| 操作 | `#1475AD` | `#69BDEB` |
| 正文 | `#203B53` | `#EAF4FB` |
| 次要文字 | `#5D7185` | `#B5C8D8` |

用户指定的 Rosé Pine 另作为可选主题保留，右键主题按钮可选择。主按钮与状态色在建议色基础上调整明度，通过实际背景上的 4.5:1 文字对比度测试。

字体采用现代无衬线体系，嵌入 Noto Sans SC 保障中文离线显示；Windows 优先本机 Segoe UI。页面标题 32px，其余角色为 17 / 15 / 14 / 13 / 12px。旧的衬线展示字体不再进入当前产物。

控件高 40px、制作按钮高 44px；控件圆角 8px、辅助面板 12px、主工作面 16px。使用 4px 基础网格，字段与大分组有不同间距。

## 桌面交互

保留原生标题栏、系统文件对话框、右键菜单和系统打开操作。Windows / Linux 使用 Ctrl，macOS 使用 Command。窄窗口将设置移到队列下方，只需垂直滚动。

作者、阅读方向、JPEG 质量和 1–8 本并发位于「更多选项」。封面以缩略图和独立预览呈现；错误有持久文字，并可打开详情。

按钮、输入框和图标操作支持键盘焦点；启用 AccessKit。自动测试从实际无障碍树中按名称找到控件，验证格式、主题、删除与快捷键制作。

装饰层静态且不接收输入；未加入持续漂浮、闪烁或背景动画。关键状态使用文字、图标与颜色共同表达。

## 验收

实际截图检查 1440×900、1280×800、1024×768 和 800×600，并检查浅色、深色及队列状态。Windows 原生 UI Automation 已用于验证格式切换、实际出书及主题切换；平台与当前验证结果见 [验证记录](VALIDATION.md)。
